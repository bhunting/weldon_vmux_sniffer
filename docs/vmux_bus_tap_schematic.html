Bill of Materials (Key Parts)

  • J1 — DT04-4P network tap (1 A, 2 B, 3 GND, 4 ckt 312)
  • D1 — SM712 bidirectional TVS array, ±6V
  • R1,R2 — 100Ω 1% 0805 series resistors
  • L1 — Würth 744235601 common-mode choke
  • U1 — ISO7241CDWR 4ch digital isolator
  • U2 — MAX3485ESA+ RS-485 transceiver
  • U3 — AMS1117-3.3 LDO (bus side)
  • U4 — 12V→5V LDO (vehicle power input)
  • PS1 — Murata MEE1S0512SC isolated DC/DC
  • C1 — 100nF X7R bypass (×4, one per IC)

Critical Design Rules

  • No termination resistors — V-MUX forbids them
  • High-impedance tap — do not drive bus in Phase 1
  • Isolation GNDs separate — never tie together
  • DIR default Low = receive-only at power-on
  • TX enable time <1µs before first data bit
  • TVS D1 before all other components on bus lines
  • Bypass caps within 1mm of each IC VCC pin
  • Twisted pair routing for A/B traces on PCB

Signal Flow — Listen Mode

  • J1 pins 1,2 → L1 CMC → D1 TVS → R1/R2
  • R1/R2 → U2 A/B pins (RS-485 differential input)
  • U2 RO → U1 isolator → J2 MCU_RX pin
  • DIR pin held Low: ~RE asserted, DE deasserted
  • U2 operates as receiver only — no bus drive
  • MCU UART receives decoded bytes on MCU_RX
  • Logic analyzer in parallel on J1 pins 1/2 for framing

Signal Flow — Transmit Mode

  • MCU asserts DIR High via GPIO
  • U2 DE enabled, ~RE disabled (bus driven)
  • MCU_TX → U1 isolator → U2 DI → bus A/B
  • Turnaround: DIR must go High >1 bit-time before TX
  • After last stop bit: DIR returns Low immediately
  • Bus returns to high-impedance listen state
  • Implement in MCU UART interrupt or DMA complete CB

PCB Layout Notes

  • Two ground planes: GND and GND_ISO — no connection
  • Isolation slot under U1 and PS1 on PCB
  • D1, L1 on board edge closest to J1 connector
  • R1/R2 as matched pair, adjacent on same layer
  • All bypass caps on same layer as IC, via-in-pad ok
  • A/B traces: 100Ω differential impedance, equal length
  • Keep MCU side traces away from bus side traces
